# Muusy-Island
Muusy Island ist eine systemweite Musiksteuerung für Windows 11 mit cleaner Glass-UI. Steuere YouTube Music in Chrome, Opera und Opera GX sowie Spotify und VLC über eine frei positionierbare Dynamic Island. Mit Play/Pause, Skip, Hotkeys, Lautstärke, Queue, App-Schnellzugriffen und Drag-to-close. Open Source unter MIT-Lizenz.
